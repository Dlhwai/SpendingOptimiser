First time connecting?

Gmail needs your own Google Desktop client. Setup is local and secure; no client JSON or tokens are stored in plaintext by this app.

One-time Google setup
  1. In Google Cloud Console, enable the Gmail API.
  2. Configure Google Auth Platform for External / Testing. Add your exact address as a test user. Request gmail.readonly and openid.
  3. Create a Desktop app OAuth client, not a Web application. Download its JSON to an owner-only location outside this repository.
  4. Import the file into your native OS credential store using your terminal:uv run --locked spending-optimiser --configure-google < /absolute/private/path/client.jsonDelete the downloaded file after successful import. Unlock Keychain, Credential Manager or Secret Service if needed. Never use a plaintext fallback.
  5. Return to http://127.0.0.1:{{ request.url.port or 80 }} and choose Connect Gmail. Google testing-mode authorization may expire after 7 days; reconnect when asked.

Full instructions and provider restrictions: docs/gmail.md. Never paste secrets into this page, chat, logs or Git. No Web-client redirect registration is required.

Returning to your workspace?

Restart clears temporary mail, not your ledger. Restore this database's saved authorization from the native OS store. No mail or network access occurs until you Load mail.
